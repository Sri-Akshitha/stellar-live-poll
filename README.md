# 🗳️ Stellar Live Poll

A real-time voting application built on the Stellar blockchain.

## 🚧 Project Status

Yellow Belt Challenge - In Progress

## 📌 About

This project is being developed as part of the Stellar Journey to Mastery program.

The application will allow users to connect their Stellar wallets, vote in a live poll, and view updated results using a Soroban smart contract.
